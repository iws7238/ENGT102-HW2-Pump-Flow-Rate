# ENGT102-HW2-Pump-Flow-Rate

## IPO Analysis

Inputs:

- Volume of water transferred in Liters
- Elapsed time of transfer in Seconds

Process:

- Divide Volume transferred bt Elapsed Time

Output:

- Flow rate in Liters per Second

## Pseudocode

START

INPUT volume
INPUT time

SET flow_rate TO (volume/time)

DISPLAY flow_rate

END
